# 《魔法博物馆》/ Magic Museum — Game Concept

> **文档目的**：本文档是项目的“创意宪法”，用于锁定游戏名称、故事背景、视觉锚点、核心循环、展馆概念、受众与范围。后续 GDD、ADR、原画/概念图工作均以此为单一信息源。
>
> **语言策略**：叙事与设计内容用中文；技术 ID、文件路径、引擎术语、节标题保留 English。
> **特别强调**：§10 与 §11 为原画/概念设计服务，读完本文档后应能直接产出博物馆整体、远古巨兽馆、自然生态馆的第一轮概念设计稿。

## 1. Elevator Pitch（电梯演讲）

> 你接手了一座被藤蔓、尘光与小动物重新占领的废弃魔法博物馆。它可能来自一封奇怪遗嘱，也可能是你用一枚会自己滚动的旧金币拍下的“低价凶宅”。你的工作不是清空这里，而是修复展品、理解精灵与动物的生活方式，让它们快乐、和谐地生活在博物馆生态中，同时让博物馆重新拥有惊奇、秩序与温柔的生命力。

**通过 10 秒测试**：玩家第一次听到这句话，就能想象出“一个卡通小男孩蹲在巨大猛犸象骨架旁，发现象头骨被苔藓精灵改成摇篮，于是轻轻寻找替代方案，让摇篮与展品都回到更好的位置”的画面。

## 3. Story Premise（故事背景）

玩家在繁忙都市里过着被日程表切碎的生活。某天，他以一种非常不靠谱的方式得到了远郊山脊上的废弃魔法博物馆。游戏不需要把这件事讲得一本正经；它应该像工作日深夜突然收到一份荒唐但无法拒绝的生活邀请。

可选的获取 / 继承方式：

1. **快递错送继承权**：玩家收到一个写着“请勿摇晃，内含不动产”的快递盒。打开后飞出一枚会打喷嚏的铜钥匙、三张逾期 87 年的门票，以及一份把玩家名字写错三次但依然生效的博物馆继承书。
2. **抽奖抽中一座馆**：公司年会安慰奖原本是“博物馆联名马克杯”，但抽奖箱被魔法展柜吃掉又吐出来，奖品变成“博物馆本体”。主持人坚持说“兑奖后不退不换”。
3. **二手平台捡漏**：玩家用一枚会自己滚动的旧金币买下“复古展柜一件，自提”。到现场才发现展柜只是入口，卖家备注写着：“买展柜送博物馆，馆内小动物概不包邮。”
4. **地图软件误导航**：玩家下班后想去最近的便利店，导航却连续播报“前方 200 米接手祖传博物馆”。到达后，闸机自动打印出写着玩家名字的馆长临时证。
5. **猫形公证员强制交接**：一只戴单片眼镜的猫坐在玩家窗台上，郑重宣布：“根据第 14 条喵款，你被一座无人认领的博物馆认领了。”玩家还没来得及拒绝，猫已经把钥匙塞进他的泡面里。

当前默认版本建议采用 **“二手平台捡漏 + 买展柜送博物馆”**：它最贴合“拥有自己的展厅 / 收藏”的愿望，也足够无厘头，能自然引出玩家从一件小物开始，意外获得整座博物馆的惊喜。

这座博物馆不像普通建筑。它外部像一座霍格沃茨式城堡博物馆，尖塔、石桥、回廊、温室与钟楼层层叠叠；内部有错落楼梯、会改变落点的展厅平台、悬空夹层、旋转书梯、被魔法托起的标本吊桥。它不是黄昏限定的“霍格沃茨”，而是强调城堡轮廓、纵深层次、魔法楼梯与奇幻空间结构。

玩家不是来“管理展品”的馆长，而是低声修复者。这里不止有精灵，还有动物；多数精灵也以动物造型出现，例如苔藓幼鹿、菌丝狐狸、水晶蜗牛、羽叶猫头鹰、骨铃鼬，只有少量人形精灵承担更强的叙事功能。

### 3.1 Tone（休憩与无厘头）

本作的主要心流仍然是繁忙工作之外的休憩：拥有自己的展厅、整理自己的收藏、看着一个空间慢慢恢复生机。但这个世界不应该过分端庄。魔法博物馆本身有点不讲道理，展品有脾气，动物会误会人类的用途，精灵经常认真地做一些很荒唐的事。

诙谐设计应遵守三条规则：

- **笑点来自误用和反差**：巨大的恐龙趾骨被当成门挡，三角龙角被小鸟当成晾衣杆，严肃展牌上会自动补一句“请勿再次把尾椎用于开核桃”。
- **笑点不破坏温柔**：玩家笑的是世界的可爱失控，不是嘲笑精灵、动物或玩家失败。
- **喜剧服务放松**：每个展馆都应有 1-3 个能让玩家会心一笑或哈哈大笑的小发现，但不把游戏变成密集吐槽或段子合集。

## 4. Core Fantasy（核心幻想）

> “我不是来征服这座废墟的。我是来听它说话，再温柔地把它扶正。”

游戏的核心不是把精灵变成展品，也不是让活生生的朋友服务于冷冰冰的陈列。正确目标是：让精灵、动物、植物、展品与建筑共同形成更好的博物馆生态。

展品修复后的理想状态应同时满足三点：

1. 展品重新具备清晰、庄重、可欣赏的陈列价值。
2. 精灵与动物的栖居环境没有被破坏，甚至变得更安全、更舒适、更有趣。
3. 博物馆因为这些生命的存在更生动，而不是因为“清除自然”变得更整洁。

情绪目标是为繁忙都市打工人提供心灵休憩的心流体验。玩家应在低压力、慢节奏、可随时停下的流程中获得“我把一个小世界照顾好了”的安定感，同时在不经意间被荒诞的小细节逗笑。它不是严肃经营一座博物馆，而是在一本正经的展陈外壳下，允许世界偷偷变得好玩。

## 5. Unique Hook（独特卖点）

**Like X, AND ALSO Y**

> Like *Unpacking*：物归其位的禅意与生活痕迹。  
> AND ALSO *A Little to the Left*：日常物件里的轻量观察谜题。  
> AND ALSO *Cozy Grove*：与小精灵建立非语言关系。  
> AND ALSO 城堡博物馆奇观：霍格沃茨式多层建筑、魔法楼梯、悬空平台与展馆纵深。

核心反差：博物馆游戏通常关于“秩序压倒野性”；本作关于“秩序与野性达成契约”。

- 没有“驱赶”按钮，只有观察、替代、迁居与共生。
- 展柜不是孤品玻璃盒，而是会被生命温柔改造的共生剧场。
- 每件关键展品碎片都不是普通收集品，而是藏在日常环境中的拟态谜题。

## 6. Puzzle Design（寻找与小解谜）

寻找物品和展品碎片时，需要经过简单的小解谜。谜题难度来自“仔细看、想一想”，而不是反应速度或复杂操作。

### 6.1 设计原则

- **拟态隐藏**：关键碎片被伪装成日常环境的一部分，例如象头骨被苔藓精灵当作摇篮，剑齿虎肋骨被用作藤架，古植物化石板被当成池塘踏石。
- **环境线索**：磨痕、苔藓走向、动物脚印、尘光回声、展牌残字共同指向碎片位置。
- **轻量操作**：旋转、对齐、移开遮挡、组合替代物、让小动物通过某个路径。
- **默认推进**：解谜成功后剧情和流程自动发展，不需要额外文本输入或分支选择。
- **不惩罚**：玩家可随时放下谜题，环境会用微光、声音、动物行为逐渐补足线索。

### 6.2 示例谜题

| 谜题 | 场景 | 发现方式 | 解法 |
|---|---|---|---|
| 象头骨摇篮 | 远古巨兽馆 | 苔藓摇篮的弧度与展台缺口吻合；摇篮下方有象牙纹理 | 找到更柔软的蕨叶吊篮，将精灵幼崽迁入，再把头骨归位 |
| 剑齿虎肋骨藤架 | 远古巨兽馆 | 藤蔓攀爬的弧线过于规则，像缺失的胸腔结构 | 调整光照让藤蔓自行松开，保留部分藤蔓作为共生装饰 |
| 缩微瀑布透镜 | 自然生态馆 | 一块“湿润鹅卵石”会折射出倒置的小森林 | 用水晶蜗牛留下的折射轨迹定位透镜，装回缩微景观观察台 |
| 古蕨化石踏石 | 自然生态馆 | 池塘踏石的叶脉与墙上残缺拓印一致 | 让青蛙和羽叶精灵先获得替代落脚点，再恢复化石板 |

## 7. Core Loops（四时间尺度）

### 7.1 30 秒微循环

```
观察异常物件
  -> 听到材质回声或看到微光线索
  -> 拿起 / 旋转 / 移开遮挡
  -> 看见精灵、动物或植物的反应
  -> 形成下一步假设
```

### 7.2 5-15 分钟展品循环

```
进入一件展品的修复任务
  -> 找到 3-6 个碎片或关键部件
  -> 解开 1-2 个轻量环境谜题
  -> 理解生命栖居需求
  -> 提供替代栖居或共生方案
  -> 展品归位并“活起来”
```

### 7.3 60-90 分钟展馆循环

```
进入一个展馆
  -> 完成 3-5 件普通展品
  -> 完成 1 件镇馆展品
  -> 展馆生态恢复运转
  -> 玩家旁观片刻，可随时保存退出
```

### 7.4 全局进程循环

```
恢复 3 个核心展馆
  -> 解锁中央大厅
  -> 触发“重启之夜”
  -> 博物馆成为动物、精灵、展品与人类共同维护的魔法生态
```

## 8. Game Pillars

### Pillar 1：修复而非征服（Restore, Don't Conquer）

玩家的目标是扶正、理解和改善环境，不做驱赶、击退、清除精灵或动物的设计。

### Pillar 2：共生即正典（Cohabitation as Canon）

完美归位不是“展柜里只有物品”，而是展品、生命与环境形成稳定关系。

### Pillar 3：发现藏在日常中（Wonder in Disguise）

重要物品不总是发光摆在路中央，而是被拟态、误用、藏入日常功能中，等待玩家通过观察发现。

### Pillar 4：城堡博物馆奇观（Layered Castle Museum）

宏观视觉必须有城堡式轮廓、错层空间、魔法楼梯、悬空回廊、深邃展厅和纵向尺度。

### Pillar 5：心流休憩（Restorative Flow）

体验服务于都市打工人的精神休息：慢、稳、可暂停、有回报、无惩罚。

---

## 9. Anti-Pillars（反支柱）

| 反支柱 | 原因 |
|---|---|
| NOT 战斗 | 战斗、驱赶、捕捉都会破坏共生主题 |
| NOT 把精灵当展品 | 精灵是朋友和生态成员，不是被陈列的物件 |
| NOT 失败惩罚 | 没有计时、Game Over、撤销限制 |
| NOT 重 UI 解谜 | 线索来自环境、材质、声音和生物行为 |
| NOT 过度文本输入 | 除玩家名字外，不要求输入；解谜后流程默认推进 |

## 10. Visual Identity Anchor（视觉锚点）

### 10.1 一句话视觉规则

> 一座具有霍格沃茨式城堡轮廓与内部错层结构的魔法博物馆，被东方博物馆的沉淀感、自然纪录片的生命奇观、以及柔和魔法光效共同重新点亮。

本作不绑定“黄昏霍格沃茨”。黄昏光可以作为某些场景的情绪工具，但核心期待是：

- 外部像城堡博物馆：尖塔、石桥、钟楼、温室、坡地、拱廊、深窗、屋顶天桥。
- 内部有多重层次：移动楼梯、交错走廊、半层平台、悬浮展台、可俯瞰的大中庭。
- 魔法设计有功能感：楼梯改变路线，展牌会自修复，标本吊桥会随呼吸起伏，窗光会指向谜题线索。
- 东方博物馆沉淀：空间中出现故宫博物院式的轴线与院落感、苏州博物馆式的留白与水景、上海自然博物馆式的现代自然展陈结构，同时保留魔法城堡的奇幻气质。

### 10.2 宏观整体造型

**外部轮廓**：博物馆坐落在城市边缘的山脊与湖泊之间，背后是深色针叶林，前方有一条废弃电车轨道通向山门。主体建筑像城堡与博物馆的混合体：中央高塔像天文钟楼，两侧是低矮展馆翼楼，玻璃温室从石墙中生长出来，屋顶有被藤蔓包裹的观景平台。

**周围环境**：湖面倒映尖塔，岸边有芦苇、石兽、旧售票亭、半埋的路牌和长满苔藓的喷泉。白天有自然纪录片般的细节：昆虫、鸟群、雨后水汽、植物卷须；夜晚则由室内展厅、玻璃温室和浮游萤光勾勒建筑层次。

**首张宏观概念图要求**：

- 视角：远景 3/4 俯视，能看到城堡博物馆整体体块和周边湖林关系。
- 必须出现：中央高塔、错层屋顶、玻璃生态温室、入口石桥、废弃电车轨道、至少一处发光展厅窗口。
- 情绪：神秘但不恐怖，废弃但不荒凉；像一处正在等待被温柔唤醒的地方。

### 10.3 角色视觉

玩家角色暂定为一个迪士尼风格的卡通小男孩，第三人称可见全身。设计要有特色，不走大众审美模板。

- 身形：偏小，四肢灵活，背着过大的修复工具包，强化“孩子面对巨型展品”的尺度差。
- 轮廓：一顶不对称旧帽子或短斗篷形成可识别剪影；衣摆、背包带和工具挂件会轻微摆动。
- 颜色：暖色衣物搭配一处冷色魔法小物，避免纯学院制服感。
- 性格：好奇、谨慎、愿意蹲下来观察，不是天选救世主。

## 11. Key Exhibition Halls（两种展馆概念）

### 11.1 远古巨兽馆（Ancient Giants Hall）

#### 展馆概念

远古巨兽馆是一座高挑石厅，结合自然历史博物馆的大型骨架陈列与魔法城堡大厅的纵向压迫感。这里展示远古猛犸象、恐龙、剑齿虎、巨鹿、古鸟、海生巨兽等骨骼或模型。某些动物形态精灵可以附身于骨骼、模型或标本，使这些死物短暂获得生命：骨架会低头闻一闻玩家，剑齿虎模型会像猫一样伸懒腰，巨鹿角会长出微光苔藓，幼年恐龙模型会因为找不到自己的尾巴而原地转圈。

视觉关键词：高拱顶、二层回廊、悬吊骨架、暖灰石材、黄铜支架、尘光、苔藓、动物形态精灵、古代生命的复苏感。

#### 核心展品设计

| 展品 | 展品状态 | 关联生命 | 修复后效果 |
|---|---|---|---|
| 远古猛犸象全骨架 | 头骨、象牙、肩胛骨、尾椎分散；头骨被当作摇篮 | 苔藓幼鹿精灵、馆内小鼩鼱 | 骨架缓慢抬头，象牙微光如月牙，幼崽搬入更柔软的蕨叶吊篮 |
| 恐龙骨架群 | 霸王龙尾椎被当成门挡，三角龙角被鸟群当成晾衣杆，迅猛龙爪被误认成开信刀 | 骨铃鼬精灵、羽叶鸟群、好奇的小蜥蜴 | 骨架恢复队列后会进行一次很庄严但略滑稽的“排练走位”，霸王龙因为尾巴刚找回而差点转身撞到展牌 |
| 剑齿虎骨骼 / 模型 | 肋骨被藤蔓当成攀爬架，颅骨符文缺失 | 菌丝狐狸精灵 | 模型获得猫科动物般的呼吸感，符文与菌丝尾光呼应 |
| 巨鹿角冠 | 鹿角被拆成走廊挂钩和鸟巢支架 | 羽叶鸟群、少量人形守馆精灵 | 鹿角归位后形成展厅上方的自然拱门，鸟巢保留在不伤害结构的位置 |

#### 碎片与谜题设计

- **猛犸象头骨摇篮**：玩家发现一个被蕨叶与苔藓包裹的摇篮形物体，只有从侧面看才能认出眼窝与鼻腔结构。解法是先用藤篮、软苔和旧窗帘制作替代摇篮，再让苔藓幼崽主动迁入。
- **霸王龙尾椎门挡**：一块“非常顺手”的门挡其实是霸王龙尾椎。玩家需要先找到会自动关门的展厅门为什么焦虑，再用一只老式黄铜镇纸替代门挡，让尾椎回到骨架上。
- **三角龙角晾衣杆**：羽叶鸟群把三角龙角当成晾羽毛的横杆。玩家不能直接拿走，需要搭建更高、更暖、更不容易被风吹倒的晾羽架。
- **象牙伪装成楼梯扶手**：一截象牙被装在半层楼梯上当临时扶手，玩家需要观察扶手端部的年轮纹与展牌上的象牙截面图一致。
- **剑齿虎肋骨藤架**：肋骨与藤蔓纠缠，不能粗暴拔开。玩家需要转动屋顶镜片，让光线照到旁边空花架，藤蔓才会缓慢迁移。
- **颅骨符文碎片**：碎片被菌丝狐狸叼去装饰新家，玩家提供一块非展品装饰骨片作为替代，狐狸归还真正碎片。

#### 原画设计稿要求

- **环境图**：站在入口下方仰视，画面中必须出现猛犸象骨架、恐龙骨架群、二层回廊、悬吊古鸟、魔法楼梯和苔藓精灵群。
- **展品图**：猛犸象骨架修复前后对比；修复前强调误用与拟态，修复后强调共生而非清空。
- **谜题图**：象头骨摇篮、霸王龙尾椎门挡、三角龙角晾衣杆任选其一做近景，要求一眼看是可爱的日常误用，仔细看才发现它是展品部件。

### 11.2 自然生态馆（Natural Ecology Hall）

#### 展馆概念

自然生态馆是一座玻璃穹顶、石质廊架与室内山谷结合的展馆，陈列奇观植物、缩微景观、生态瓶、矿物水景、古蕨温室与可进入的第一视角小世界。某些精灵拥有“缩微沉浸”技能，可以让玩家进入缩微景观，以第一视角体验微型森林、苔藓峡谷、露珠湖泊和花粉风暴。

视觉关键词：玻璃温室、巨大叶片、微型瀑布、雾气、水面反光、奇观植物、东方园林借景、自然纪录片镜头感。

#### 核心展品设计

| 展品 | 展品状态 | 关联生命 | 修复后效果 |
|---|---|---|---|
| 缩微雨林生态瓶 | 透镜、循环水轮、种子星盘缺失 | 水晶蜗牛、羽叶猫头鹰精灵 | 玩家可进入缩微雨林第一视角，看到露珠像湖、苔藓像森林 |
| 奇观植物“月脉莲” | 花瓣闭合，根系缠住展牌与水渠 | 莲叶蛙、少量人形园丁精灵 | 花瓣随玩家脚步缓慢张开，水渠恢复循环 |
| 古蕨化石与活体蕨园 | 化石板被当作池塘踏石 | 小鱼、青蛙、苔藓精灵 | 化石板归位后，活体蕨叶沿其纹路生长成自然注释 |

#### 碎片与谜题设计

- **缩微瀑布透镜**：看似一块湿润鹅卵石，只有被水晶蜗牛爬过时才出现折射光环。玩家用折射轨迹找到正确安装角度。
- **种子星盘伪装成餐盘**：星盘被动物们当作喂食盘，玩家要根据盘面种子排列与墙上星图残影对齐，确认它的展品身份。
- **古蕨化石踏石**：玩家先搭建临时浮叶桥，让青蛙和小鱼不失去路径，再把化石板归位。
- **月脉莲水渠**：通过旋转三片石叶调整水流，水流正确时花瓣上的脉络会亮起。

#### 缩微沉浸体验

进入缩微景观时，镜头临时切换为第一视角。玩家不是战斗或采集，而是观察尺度变化：露珠变成湖泊，花粉像金色雪，蜗牛爬痕像玻璃道路，远处现实世界的展厅声音变成低沉回响。体验时间短，每次 2-5 分钟，作为解谜奖励与情绪休息点。

#### 原画设计稿要求

- **环境图**：玻璃穹顶下的室内生态峡谷，远处可见东方园林式水面与石桥，近处有巨大叶片和微型展台。
- **展品图**：缩微雨林生态瓶外观 + 玩家进入后的第一视角画面。
- **谜题图**：湿润鹅卵石/缩微瀑布透镜的拟态近景，要求有“日常物件中藏着奇观”的惊喜。

## 12. Target Player Profile

### 核心受众

- **年龄**：25-45 岁。
- **类型**：成人 cozy 玩家、自然纪录片观众、奇幻视觉爱好者、概念艺术爱好者。
- **常玩**：*Unpacking* / *A Little to the Left* / *Stray* / *Spiritfarer* / *Cozy Grove*。
- **偏好**：探索、观察、舒适心流、环境叙事、低压力完成感。

### 次级受众

- **中国博物馆沉淀爱好者**：喜欢故宫博物院的历史层积、苏州博物馆的空间留白与园林气质、上海自然博物馆的自然展陈与生命演化叙事；本作应有显著的东方中华民族展览元素，而不只是西式自然史馆。
- **自然纪录片观众**：这个方向必须坚持。镜头语言、生态细节、动物行为和植物奇观要能让玩家联想到《地球脉动》《我们的星球》式的自然惊奇。
- **奇幻视觉、原画/概念爱好者**：本作的城堡博物馆、巨兽骨架、缩微景观与共生生态本身就是视觉卖点。
- **繁忙都市打工人**：需要一个可随时保存、没有惩罚、能慢慢整理心情的心灵休憩空间。

### 不为谁设计

- 硬核动作玩家。
- PvP / 竞技玩家。
- 要求强目标强引导的任务型玩家。
- 追求战斗成长、装备数值、Boss 压力的玩家。

## 13. Player Character & Interaction Decisions

| 问题 | 决策 |
|---|---|
| Q1 玩家角色是否有视觉形象？ | 有。暂定为一个迪士尼风格的卡通小男孩，第三人称全身可见。造型要有特色，不要大众审美模板。 |
| Q2 是否有解谜难度选项？ | 同意候选：MVP 无难度选项，通过环境线索密度和渐进提示调节。 |
| Q3 铝牌/展牌共撰是否需要玩家输入或选择？ | 无需输入和选择。解谜后默认由剧情/流程发展生成展牌变化。 |
| Q4 是否有保存点限制？ | 随时保存，符合 cozy 和无惩罚原则。 |
| Q5 玩家名字如何处理？ | 游戏开始输入玩家名字，片尾或关键展牌可使用。 |

## 14. Technical Considerations

### 引擎选择：Unreal Engine 5

| 技术 | 用途 | 关键性 |
|---|---|---|
| Lumen | 城堡博物馆多层空间、玻璃温室、室内自然光 | 关键 |
| Niagara | 尘光、花粉、苔藓微粒、精灵轨迹 | 关键 |
| Nanite | 高密度石雕、骨骼、展品、植物表面 | 关键 |
| Control Rig | 精灵、动物、骨架附身后的微动作 | 关键 |
| MetaSounds | 物件触感、脚步、展厅回声、缩微景观声场 | 中 |
| Chaos Physics | 可拾取碎片、轻量摆放、布料与藤蔓辅助 | 中 |

### 风险

- 大量可交互物件 + 高密度植物 + Lumen 可能导致性能压力。
- 动物形态精灵需要足够细腻的非语言动画，否则共生主题会变空。
- 缩微景观切换第一视角需要控制范围，避免变成另一个完整玩法系统。

## 15. MVP Definition

> **MVP = 远古巨兽馆完整切片。**

MVP 只做 1 个完整展馆，但必须包含本作核心体验：

- 1 个可探索的远古巨兽馆。
- 1 件镇馆展品：远古猛犸象全骨架。
- 3 件普通展品：恐龙骨架群、剑齿虎骨骼/模型、巨鹿角冠。
- 至少 3 种生命：苔藓幼鹿精灵、菌丝狐狸精灵、馆内小动物。
- 至少 4 个拟态寻找谜题：象头骨摇篮、霸王龙尾椎门挡、三角龙角晾衣杆、肋骨藤架。
- 完整共生流程：观察 -> 解谜 -> 替代栖居 -> 展品归位 -> 展馆生态恢复。
- 第三人称小男孩角色可见。
- 随时保存。

MVP 暂不包含自然生态馆的完整玩法，但需要完成 1 张自然生态馆概念图和 1 个缩微沉浸灰盒验证。
