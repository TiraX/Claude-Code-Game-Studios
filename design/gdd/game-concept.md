# 《精灵与展柜》/ Sprites & Showcases — Game Concept

> **文档目的**：本文档是项目的"创意宪法"，用于锁定游戏的视觉锚点、核心循环、支柱与范围。
> 后续所有 GDD、ADR、原画/概念图工作均以此为单一信息源。
>
> **本文档语言策略**：叙事/设计内容用中文；技术 ID、文件路径、引擎术语、节标题保留英文。
> **特别强调**：本文档的 §10 与 §11 为原画/概念图制作服务，视觉描述密度高于其他章节。

## 1. Elevator Pitch（电梯演讲）

> 在被遗忘的魔法博物馆里，你不是策展人，而是与小精灵协商的修复者。每件展品都被拆散藏在角落、被精灵改作了家具——你必须先理解它们的需求，才能让骨架、星图、藤蔓重新归位。归位不是终点，**让精灵成为展品的一部分**才是。

**通过 10 秒测试**：玩家第一次听到这句话即能想象出"在烛光下蹲下、与一只苔藓精灵协商象牙归位"的画面。

## 3. Core Fantasy（核心幻想）

> "我不是来征服这座废墟的。我是来听它说话，再温柔地把它扶正的。"

玩家扮演一位**低声修复者**——你的力量不在于挥舞魔杖驱赶精灵，而在于**蹲下、观察、试探、退让**。

当一根象牙被野葛缠住、当一块化石成为苔藓精灵的卧榻，征服式的整理是错误答案；正确答案是**让自然与展品共同进入展柜**——铭牌上多一行小字："本展品由苔藓精灵共同维护"。

**情感目标**：玩家应在每一次成功归位时，体验到 **"啊——它一直在等这一刻"** 的顿悟，而非 **"我搞定了"** 的征服快感。

---

## 4. Unique Hook（独特卖点）

**"Like X, AND ALSO Y"**：
> Like *Unpacking*（物归其位的禅意），
> AND ALSO 像 *Cozy Grove*（与精灵建立非语言关系），
> AND ALSO 像 *Hogwarts Legacy 的环境光*（黄昏石殿、尘光、烛火）

**核心反差**：博物馆类型游戏通常关于**秩序压倒野性**；本作关于**秩序与野性达成条约**。这个反差贯穿所有机制：
- 没有"清除"按钮——只有"协商"
- 铭牌不是策展人的独白——是与精灵的共撰
- 展柜不是孤品的玻璃棺——是共生剧场

## 5. MDA Framework

### 5.1 Aesthetics（美感优先级）

1. **Discovery（探索）** — 发现物件碎片、精灵巢穴、墙缝纸条、铭牌注释
2. **Expression（表达）** — 多种合理归位方案；每位玩家的展厅都将有微妙差异
3. **Narrative（叙事）** — 通过物件、铭牌、墙缝、精灵反应讲述博物馆与魔法世界的故事
4. **Sensation（感官）** — 黄昏尘光、皮革、苔藓、骨头的触感反馈

明确不在前三的：Challenge / Competition / Fellowship。

### 5.2 Dynamics（动态）

- **观察 → 假设 → 试探 → 共情 → 归位** 的协商节奏
- 玩家的"假设"需要经过 1-3 次试探修正，每次试探都给精灵一次反馈机会
- 精灵的反馈不通过 UI——通过身体姿态、毛色变化、藤蔓伸缩等环境语言

### 5.3 Mechanics（机制）

- **碎片对位（Fragment Placement）**：在候选展柜上预览碎片，吻合时有触感反馈
- **寄居谜题（Cohabitation Puzzle）**：识别精灵需求 → 提供替代品 → 共同入展柜
- **铭牌共撰（Plaque Co-authoring）**：玩家选择铭牌措辞（学术 / 共生 / 诗意）
- **尘光节律（Dust-light Cadence）**：黄昏永驻的环境光循环作为节奏脉冲

## 6. Player Motivation Profile

### 6.1 Self-Determination Theory（SDT）

| 心理需求 | 本作如何满足 |
|---|---|
| **Autonomy（自主性）** | 多种归位方案；精灵协商有多条出路；铭牌措辞自定 |
| **Competence（胜任感）** | 识图、识物、识精灵的渐进式眼力；逐渐看出更多线索 |
| **Relatedness（关联性）** | 与精灵的非语言关系；与建筑、与博物馆历史的情境共鸣 |

### 6.2 Bartle 玩家类型

- **主**：Explorer（探索每一面墙、每一个角落）+ Achiever（完成展品归位）
- **次**：Storyteller（共撰铭牌、推测博物馆历史）
- **不是**：Killer（无对抗）/ Socializer（单人无社交）

### 6.3 Quantic Foundry 动机模型

- **核心象限**：Discovery / Design / Story（创意-探索）
- **次要**：Completion（轻度收集）
- **完全不强调**：Competition / Destruction / Power

### 6.4 Flow（心流）设计

- 每个谜题在 5-15 分钟内完成一次 Aha
- 难度由 **"能看见多少线索"** 调整（视觉密度），而非反应速度
- 无失败惩罚，玩家可永远反悔；卡住时环境会逐渐"发光"提示
- 关键自然休止点：每个展厅完成后的"运转一刻"——展厅自动恢复运转，玩家旁观片刻

## 7. Core Loops（四时间尺度）

### 7.1 30 秒微循环

```
触摸物件 → 听到回响纹路（材质音 + 微光提示）
    → 拾起 → 走到候选展柜
    → 看到精灵反应（毛动 / 藤伸 / 蛞蝓滑开）
    → 决定下一步（继续试探 / 退后观察 / 寻找替代方案）
```

**关键反馈**：每个动作都必须在 0.3 秒内有触感、视觉、听觉的至少 2 项反馈。

### 7.2 5 分钟中循环

```
进入一件展品的"修复任务" → 收齐所有碎片（通常 4-6 块）
    → 识别寄居精灵需求（观察其当前栖居）
    → 提供替代家（用现有物件组合）
    → 碎片归位 → 铭牌共撰 → 展品"亮起"
```

### 7.3 会话循环（30-90 分钟）

```
进入一个子展厅 → 完成 3-5 件展品 + 1 件镇厅展品
    → 展厅"恢复运转"（机关启动 / 灯光全亮 / 音乐回归）
    → 自然休止点（玩家旁观，可保存退出）
    → 进入下一个展厅
```

### 7.4 进程循环（数日-数周）

```
修复 3 个展厅（MVP 后扩展至 7 个）
    → 解锁博物馆中央大厅（"心脏"）
    → 触发"重启之夜"：所有精灵以共生形态回归展柜
    → 片尾铭牌：本馆由 [玩家名] 与 [N] 位精灵共同修复
```

## 8. Game Pillars

> **5 条已锁定支柱**。每条支柱是一把"决策刀"——当设计意见冲突时，支柱说了算。

### Pillar 1：复原而非征服（Restore, Don't Conquer）

- **定义**：所有机制必须让玩家"扶正"而非"清除"
- **设计测试**：当我们犹豫某机制时，问：它让玩家更接近"扶起这件物品"还是"踢开这只精灵"？
- **后果**：取消任何驱赶 / 击退 / 强制移除精灵的设计

### Pillar 2：尘光节奏（Dust-light Cadence）

- **定义**：黄昏永驻、尘光浮动是节奏的主旋律，不允许打断
- **设计测试**：这个反馈/动画是否破坏了"被时间温柔包浆"的整体调性？
- **后果**：无快速 UI 弹窗、无屏幕震动、无强烈音效冲击

### Pillar 3：情境叙事（Diegetic Narrative）

- **定义**：故事写在物件、墙缝、铭牌上，绝不靠对话框推送
- **设计测试**：能否完全移除任何浮动 UI 文本，玩家依然能理解？
- **后果**：无 NPC 对话框、无任务提示、无强制教程

### Pillar 4：触感真实（Tactile Reality）

- **定义**：物件有重量、纹理、温度反馈；魔法是"被自然回收的低语"
- **设计测试**：玩家拿起一根象牙时，能否感受到它的密度与重量？
- **后果**：高质量的物件物理 + 多层触感反馈（音、光、震、重）

### Pillar 5：共生即正典（Cohabitation as Canon）

- **定义**：展品归位的最高形态是与精灵共同入展，而非孤品
- **设计测试**：本展品的"完美归位"是否邀请了精灵共栖？
- **后果**：每件展品都设计有共生归位选项，且共生归位的铭牌、奖励比孤品归位更丰厚

---

## 9. Anti-Pillars（反支柱）

> **3 条已锁定**。明确"我们不做什么"是防止范围蔓延的最有效工具。

| 反支柱 | 原因 |
|---|---|
| **NOT 战斗** | 任何形式的战斗（驱赶、击退、消除精灵）违反 Pillar 1 与 Pillar 5 |
| **NOT 失败惩罚** | 没有计时、Game Over、撤销限制；玩家压力源是协商难度而非时间/资源 |
| **NOT 对话树** | 不引入任何 NPC 对话框 UI；违反 Pillar 3 |

**"听起来很酷但我们不做"清单**（防止后期范围蔓延）：
- ✗ 战斗系统、咒语对决、魔杖动作
- ✗ Boss 战、计时挑战、永久死亡
- ✗ 多人合作、PvP
- ✗ 角色对话树、好感度数值
- ✗ 经济系统、商店、货币
- ✗ 装备系统、技能树、能力升级

## 10. 🎨 Visual Identity Anchor — 黄昏霍格沃茨（Hogwarts in Twilight）

> **本节是项目的视觉宪法。**所有美术工作（原画、概念图、3D 资产、VFX、UI）均必须通过本节的"设计测试"。
> 本节将在 `/art-bible` 阶段扩展为完整美术圣经，但锚点不可更改。

### 10.1 一句视觉规则

> **石、木、尘三者权重相等，魔法藏在攀附其上的生命中。**

这句话的含义：
- **石**：建筑结构（哥特肋拱、砂岩柱、石板地）
- **木**：展柜、家具、木梁（带岁月浆色）
- **尘**：黄昏光柱中可见的浮尘、地面薄苔
- **魔法不是主角**——它是"攀附在石木之上"的生命气息（精灵、藤蔓、菌丝、烛火）

### 10.2 三条支撑原则（含设计测试）

#### 原则 1：风格化 PBR（Stylized PBR）

- **定义**：写实材质 + 微提饱和度（+10%~15%）+ 边缘柔化轮廓光（rim light）
- **设计测试**：当一块化石与一片苔藓同框，材质要让两者都"可触摸"——既不写实到冰冷，也不卡通到失真
- **参考**：*Tiny Glade*、*Hogwarts Legacy* 的近景物件
- **不接受**：纯卡通明暗（cel-shading）/ 极致超写实（电影 CG）

#### 原则 2：被自然回收（Reclaimed by Nature）

- **定义**：所有魔法痕迹都被苔藓、藤蔓、地衣、菌丝重新编织
- **设计测试**：任何展柜都不能"全新"——必有 1+ 处植物 / 精灵 / 时间痕迹
- **后果**：禁止"开箱即净"的展品；每件展品至少有一处"被自然回收"的设计语言

#### 原则 3：黄昏永驻（Eternal Twilight）

- **定义**：日光永远停在 17:30 左右，烛火与尘光是主光源
- **设计测试**：场景内不应出现正午硬阴影；阴影必须柔和、有体积感
- **技术实现**：UE5 Lumen + 大量 area light + 体积雾（volumetric fog）+ 尘埃粒子（Niagara）

### 10.3 色彩哲学

#### 基底色（90% 画面占比）

| 颜色 | Hex | 用于 |
|---|---|---|
| 暮蓝（Twilight Blue） | `#2C3E50` | 石材阴影、远景、天空透出 |
| 旧木（Aged Wood） | `#5C4033` | 展柜、木梁、家具基底 |
| 烛光金（Candle Gold） | `#D4A55E` | 烛火、黄昏光柱、铭牌烫金 |

#### 魔法点缀色（仅用于精灵与魔法痕迹，<10% 画面占比）

| 颜色 | Hex | 用于 |
|---|---|---|
| 青绿（Verdant Green） | `#4FC2A8` | 苔藓精灵、植系魔法、藤蔓荧光 |
| 紫罗兰（Violet Glow） | `#7B5BA6` | 星图、能量符文、菌丝狐尾 |
| 琥珀红（Amber Ember） | `#C8612D` | 烛芯余火、火系精灵（远古巨兽馆罕见） |

#### 禁忌色

- **纯白 `#FFFFFF`**：打破"被时间温柔包浆"调性
- **纯黑 `#000000`**：阴影应是暮蓝偏紫，而非死黑
- **霓虹色**（如纯青 `#00FFFF`、纯品红 `#FF00FF`）：违反"风格化 PBR"原则

### 10.4 精灵设计原则

精灵设计必须符合"被自然回收"主题——每只精灵都是某种自然元素与魔法的混合体：

| 精灵 | 描述 | 栖居 |
|---|---|---|
| **苔藓精灵（Moss Sprite）** | 球状苔团身体，细藤足，眼睛是两点暖光 | 骨架、化石之间 |
| **水晶蛞蝓（Crystal Slug）** | 半透明矿石壳，缓慢爬行，留下短暂折射轨迹 | 矿石展柜、水池边缘 |
| **菌丝狐（Mycelium Fox）** | 木色短毛，尾巴是发光菌丝伞，足迹生小蘑菇 | 木质标本柜、档案柜 |
| **(更多)** | 每个展厅 1-2 种特色精灵 | 见各展厅设计 |

**精灵设计共同要求**：
- 体型小（30-60cm 等效）——不能有压迫感
- 无敌意眼神——眉眼柔和，遇到玩家好奇而非警戒
- 动作慢——非瞬移、非跳跃式，像被时间放慢的小动物

## 11. 🏛️ 关键展厅：远古巨兽馆 — 环境与展品视觉规范

> **本节为概念图绘制服务，描述密度高于其他章节。**
> 其余展厅在 `/art-bible` 与各展品 GDD 中以同等密度展开。
> 用户的工作流程：基于本节描述完成原画/概念图 → 反哺确定最终美术风格。

### 11.1 远古巨兽馆 — 整体氛围

#### 建筑结构

- **形制**：哥特肋拱穹顶（Hogwarts Great Hall 比例感）
- **尺寸**：长约 35 米，宽约 18 米，穹顶最高点 18-22 米
- **石材**：暖灰砂岩，肋拱处有手工凿痕（凿痕不规则，强化"古老手工"感）
- **柱列**：两排粗石柱（直径 1.2 米，柱身有古代壁刻浮雕，部分被苔藓覆盖）
- **入口**：双开重型木门（高 4 米），门把是兽角形铜环
- **二楼回廊**：环展厅一周的悬空石栏，部分栏杆已残破（玩家不会摔落，仅视觉效果）

#### 光源构成

| 光源 | 颜色 | 强度 | 描述 |
|---|---|---|---|
| **主光：穹顶花窗** | `#D4A55E` 烛光金 | 强 | 4-5 道柱状黄昏直射光，可见尘埃浮游（Niagara 粒子，密度中） |
| **副光：墙壁悬浮烛火** | `#FFB871` 暖橙 | 中 | 12-16 处魔法烛火，光晕半径 2 米，缓慢飘动 |
| **氛围光：体积雾** | `#5C7080` 偏蓝灰 | 弱 | 全场低浓度体积雾，远处更浓，营造"深邃感" |
| **暗角** | — | — | 展柜下方与穹顶死角是真实阴影，但不至全黑 |

#### 地面与积尘

- **石板地面**：30cm × 30cm 方石，边角磨损；约 30-40% 区域被薄苔（`#4FC2A8` 青绿）覆盖
- **踩痕**：玩家行走会留下短暂踩痕（粒子 + decal，2 秒淡出）；走过苔藓区，苔藓微弯
- **散落物**：地面零星散落叶片、骨片、纸条（部分是收集物碎片）

#### 环境声学

- 脚步声有轻微回响（高顶大厅声学，混响时间 2-3 秒）
- 远处可闻骨架间苔藓精灵的低咕声（5-15 秒间隔）
- 烛火细微燃烧声
- 偶尔的木梁吱呀声（10-30 秒间隔）

### 11.2 镇厅展品 #1：长牙巨兽全骨架

> **参考形象**：猛犸象 + 龙骨融合体（暗示这是魔法世界的变体生物）

#### 物理规格

- **身长**：6.5 米
- **肩高**：3.5 米
- **象牙**：呈不对称螺旋（左短右长，左象牙带分叉，右象牙更光滑）
- **骨骼材质**：象牙白偏暖（`#E8DCC0`），有细密纵向裂纹与岁月浸染的茶渍色（`#A88A5C`）
- **特殊细节**：颅骨左眼窝上方有一处古代符文烙印（已模糊，紫罗兰微光）

#### 共生精灵

- **1 只苔藓精灵**居住于颅骨内
- 玩家归位过程中，精灵会从眼窝探出，眨眼，然后缩回
- 完美归位后，精灵选择留在颅骨内成为"看守"

#### 碎片设计（玩家需收集 5 块）

| # | 碎片 | 位置 | 寄居 / 障碍 | 协商方案 |
|---|---|---|---|---|
| 1 | **左象牙** | 二楼栏杆，被野葛缠绕 | 一束魔法野葛 | 不可砍断；引导藤蔓爬向另一侧的石柱（用一块温暖的化石作"诱饵"） |
| 2 | **右象牙** | 半截嵌在石墙裂缝里 | 水晶蛞蝓家族（3 只） | 用替代矿石（地面散落的紫水晶碎片）引导蛞蝓迁移到附近展柜 |
| 3 | **左前肢股骨** | 倒插地面苔藓堆中 | 已成为某苔藓精灵的"靠枕" | 提供更舒适的替代品（旧绒毛标本的鞍垫） |
| 4 | **尾椎** | 角落水池里 | 水池映着穹顶花窗 | 简单：从水中捞出，水面会暂时打破倒影然后恢复 |
| 5 | **下颌骨** | 天花板悬挂蜘蛛网吊着 | 蜘蛛精灵已迁出 | 安全可取；轻拉蛛丝即可 |

#### 完成态

- 骨架立于中央展台，由黄铜支架辅助（支架本身有岁月铜锈）
- 颅骨内苔藓精灵成为"看守"，眨眼频率与展厅烛火同步
- 铭牌追加共生注释："本展品的灵性由苔藓精灵共同延续"
- 展厅穹顶 1 道光柱缓缓移动到骨架上方，作为"完成奖励"

### 11.3 镇厅展品 #2：剑齿兽颅骨与脊柱

> **参考形象**：剑齿虎 + 古代魔兽（颅骨刻有衰退魔法符文）

#### 物理规格

- **颅骨长**：1.2 米；獠牙长 70cm（弯刀形）
- **脊柱节数**：18 节，部分缺失（玩家需找回 4 块）
- **材质**：偏冷灰白（`#D8CFC0`），符文残痕泛紫罗兰微光（`#7B5BA6`，呼吸式脉动）

#### 环境位置

- 靠左侧墙的低展台（高 1.2 米）
- 展台周围有半圈倒下的展柜玻璃（一块块拼图式碎片，玩家可拾取重组玻璃罩）

#### 共生精灵

- **菌丝狐 1 只**，住在脊柱缝隙
- 它会"借走"3 块小骨片当装饰（玩家需先找出借走的骨片）

#### 协商谜题

- **核心**：菌丝狐不会归还借走的骨片，除非有更舒适的替代家
- **解法**：
  1. 在附近找到一个旧档案柜（已倒地）
  2. 扶正档案柜
  3. 在柜内铺上苔藓 + 一块装饰骨片（从下方游戏中找到的"装饰用替代品"，非展品)
  4. 菌丝狐迁入新家，归还借走的骨片

#### 完成态

- 颅骨置于展台中央，脊柱整齐排列（玻璃罩可选：恢复或省略——影响铭牌措辞）
- 菌丝狐在新档案柜中露头，尾巴菌丝光偶尔点亮
- 符文残痕的紫罗兰光与菌丝狐的尾巴形成视觉呼应

### 11.4 普通展品（建议 3 件，留待 `/design-system` 展开细节）

#### 11.4.1 古蕨化石板

#### 11.4.2 巨型海螺角

## 13. Target Player Profile

## 14. Technical Considerations

### 引擎选择：Unreal Engine 5

| 技术 | 用途 | 关键性 |
|---|---|---|
| **Lumen** | 全局光照对"黄昏永驻"开箱即用 | 关键 |
| **Niagara** | 尘光、苔藓波动、精灵轨迹粒子 | 关键 |
| **Nanite** | 高密度建筑细节（肋拱、浮雕、石材） | 关键 |
| **MetaSounds** | 触感真实的物件 / 脚步音 | 关键 |
| **Animation Blueprint + Control Rig** | 精灵的非语言表达动画 | 关键 |
| **Chaos Physics** | 物件拾取 / 放置的真实重量感 | 中 |

### 平台与性能目标

- **首发平台**：Steam（PC，Win10+）
- **最低配置**：GTX 1660 / RX 5600 XT（中等画质 1080p 60fps）
- **推荐配置**：RTX 3060 / RX 6600（高画质 1080p 60fps，Lumen 软件 RT）
- **目标分辨率**：1080p / 1440p；4K 通过 DLSS / FSR 支持
- **存储**：约 30-50 GB（含高清纹理）

### 关键技术风险

- 大量物件交互（拾取/放置/物理）+ Lumen + 高密度植被 → 性能挑战
- 精灵 AI 的"非语言反馈"需要细腻动画 + IK，工作量大
- 苔藓 / 植被的实时交互响应（玩家路径上的踩痕、藤蔓引导）

## 15. Risks & Open Questions

### 15.1 设计风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| "协商"机制门槛过高，玩家不理解精灵需求 | 高 | 通过环境视觉线索强化（精灵眼神、物件痕迹）；前 30 分钟引导式微教程（情境化，无 UI） |
| 玩家可能感到"无目标"（cozy 类目的固有风险） | 中 | 展厅本身是天然的章节单元；进入新展厅 = 自然目标 |
| 铭牌共撰可能被忽略 | 低 | 铭牌写作过程要有触感反馈；不写也不强制，但完成的铭牌点亮展品 |

### 15.2 技术风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| UE5 + 高密度植被 + 大量交互可能拖慢帧率 | 高 | MVP 限定 1 展厅；早期性能 spike；考虑 DLSS / FSR；植被 LOD 严格 |
| 精灵动画工作量爆炸 | 中 | 精灵种类限定（前期 3 种，全作 ≤8 种）；动画复用 + 程序化变化 |
| Lumen 在某些硬件上性能不达标 | 中 | 提供 SSGI 备用方案；最低配验证 |

### 15.3 市场风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| Cozy 类目竞争激烈（每月 N 款新作） | 高 | 视觉锚点"黄昏霍格沃茨"+ 协商机制是差异化；早期 trailer 必须主打这两点 |
| 视觉风格对部分玩家"太静态" | 中 | Trailer 中加入精灵互动、展品归位的"亮起"瞬间，强化动感 |

### 15.4 范围风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| 7 个展厅是巨大的内容工作量 | 高 | 严格遵守 MVP→3 展厅→可选 V2/DLC；每展厅都必须可独立销售 |
| 展品视觉密度高 → 美术工作量大 | 高 | 展厅模块化 + 资产复用；每展厅约 8 件展品而非 15+ |

### 15.5 待解问题（Open Questions）

- [ ] **Q1**：玩家角色是否有视觉形象？（手部？全身？无形）
  - 候选：仅手部可见（强化第一人称式亲密感，但已选第三人称）/ 全身有形（与精灵同框增强情感）
  - **倾向**：第三人称全身有形，但形象简约（剪影感，避免抢戏）
- [ ] **Q2**：是否有解谜难度选项？
  - 候选：无（统一难度，靠环境线索调节）/ 有"提示密度"开关（高/中/低）
  - **倾向**：MVP 无难度选项，根据 playtest 数据决定
- [ ] **Q3**：铭牌共撰是文本输入还是选择项？
  - 候选：自由文本输入（表达自由，但难本地化）/ 三选一文风（学术 / 共生 / 诗意）
  - **倾向**：MVP 用三选一，V2 考虑解锁自由输入
- [ ] **Q4**：是否有保存点限制？
  - 候选：随时保存 / 仅在展厅之间保存
  - **倾向**：随时保存（符合 cozy 反失败惩罚原则）
- [ ] **Q5**：玩家姓名 / 头衔是否在片尾出现？
  - 候选：可在片尾铭牌中出现 / 完全匿名
  - **倾向**：可选——玩家可在游戏开始时输入，结尾铭牌使用

## 16. MVP Definition

> **MVP = 1 个展厅完整切片（远古巨兽馆）**

### 16.1 MVP 内容范围

- **1 个展厅**：远古巨兽馆，完整氛围（建筑、光照、声音、地面）
- **5 件可归位展品**：长牙巨兽 + 剑齿兽 + 古蕨化石 + 巨型海螺 + 远古鸟爪
- **3 种精灵**：苔藓精灵 / 水晶蛞蝓 / 菌丝狐
- **完整循环**：30s / 5min / 会话循环全部可玩
- **展厅恢复运转**：完成后展厅"心跳"光波 + 烛火全亮的庆祝时刻
- **目标体验时长**：90-120 分钟

### 16.2 MVP 不包含

- ✗ 中央大厅 / 其他展厅
- ✗ 主线剧情（"重启之夜"）
- ✗ 高级铭牌共撰系统（MVP 用三选一）
- ✗ 玩家自定义姓名 / 头衔
- ✗ 多语言（仅英语 + 中文）

### 16.3 MVP 验证目标

- [ ] **Aha 比率 ≥70%**：playtest 玩家在每个展品归位时报告"啊——它一直在等这一刻"的情感反应
- [ ] **完整体验时长 90-120 分钟**：80% 玩家在此区间完成
- [ ] **协商理解率 ≥80%**：玩家无需 UI 提示即能理解精灵需求
- [ ] **退出意愿 <20%**：MVP 完成后，<20% 玩家表达"我玩够了"
- [ ] **视觉好评率 ≥85%**：trailer 投放后的早期社交媒体反馈

### 16.4 进入 Tier 1 的条件

- 上述 5 项验证目标全部达成
- 性能稳定（1080p 60fps 中等配置）
- 美术风格已定型，可批量生产其他展厅资产

## 17. Scope Tiers

### Tier 0：MVP（首要目标）

- **范围**：远古巨兽馆 1 个展厅
- **时长**：90-120 分钟
- **目的**：验证核心循环、视觉锚点、协商机制
- **状态**：📋 当前规划中

### Tier 1：小型完整作（核心发布）

- **范围**：远古巨兽馆 + 自然生态馆 + 第三馆 TBD（建议：星图天文馆 / 古籍图书馆 / 魔药生灵馆）
- **时长**：6-8 小时
- **目的**：Steam 首发版本
- **状态**：⏳ Tier 0 验证后启动

### Tier 2：完整作（可选 V2 / DLC）

- **范围**：7 个展厅 + 中央大厅 + "重启之夜"主线
- **时长**：15-20 小时
- **目的**：完整愿景
- **状态**：🔮 远期可选

### 状态门控

- **进入 Tier 1**：当且仅当 Tier 0 完成且玩家测试验证 Aha 比率 ≥70%
- **进入 Tier 2**：当且仅当 Tier 1 商业化成功（销量 > 阈值，评分 > 阈值，社区呼声）
- **可终止节点**：每个 Tier 完成后都是可独立销售 / 终止的状态
