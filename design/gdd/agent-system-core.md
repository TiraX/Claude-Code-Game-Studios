## 1. Overview

Agent 系统是暖湾的玩法核心——七位拥有独立专业知识、审美偏见和记忆能力的动物伙伴，通过自然语言与玩家协作，将岛屿愿景转化为真实存在的空间。

系统由三条主线交织构成：

**对话主线**：玩家用语言描述意图，Agent 通过 LLM 理解、追问、提案，直到双方达成一致。沟通本身是游戏内容，不是通向建造的界面。

**生成主线**：方案确认后进入全息蓝图预览——拖拽定位，语言调造型——最终触发 3D 生成 API。生成结果以「初降」状态落入世界，所有意外都是礼物，没有失败。

**主动主线**：Agent 不是被动工具。生机度变化、区域久未修缮、季节转换时，伙伴会主动走来，带着自己的发现与困惑。岛屿是活的，因为有人在关心它。

## 2. Player Fantasy

**中期体验（游玩 1–3 小时）**

玩家对着里虹随口说「那片坡总感觉差点什么」，里虹没有追问，叫来了苍狐。苍狐说它知道是什么——上次那棵老松离坡顶太近，压住了整个天际线。它想在坡脚加一层野草过渡。玩家说「可以，但别太整齐」，苍狐略显不耐烦地回答「我知道」。全息蓝图展开，玩家走进去，把其中一丛草往左拖了一点。确认。生成结果落地——形态比预想的更蓬松，草的根部延伸到石缝里。苍狐沉默了一秒说「……意外地好」。

这一刻玩家没有「完成了什么任务」的感觉，而是「做了一件只有我们才能做出来的事」。

**长线体验（游玩数周后）**

某天傍晚，里虹主动跑来，说北边的水潭最近一直在发光，宽尾獭说是地下泉眼的问题，但苍狐说不像。玩家跟着里虹走过去，发现那里已经聚集了三位伙伴，各自看着水面说话。玩家没有下任何指令——只是站在那里，听它们讨论。

这是一座真的有人在住的岛屿。

## 3. Detailed Rules

### 3.1 最小游戏循环（Minimum Viable Loop）

每一次完整的创作循环由以下阶段构成，任何阶段均可暂停：

```
[1] 玩家发出意图
        ↓
[2] 里虹解析 → 路由专业 Agent（或追问澄清）
        ↓
[3] 专业 Agent 生成文字提案（1–3 个方向）
        ↓
[4] 玩家选择方向 / 语言微调造型
        ↓
[5] 进入全息蓝图预览
        → 拖拽调整位置
        → 语言调整造型细节（循环直到满意）
        ↓
[6] 玩家确认「建造」
        ↓
[7] 触发 3D 生成 API（异步）
        ↓
[8] 生成结果以「初降」状态落地
        → Agent 对结果做出反应
        → 玩家观察、评论或沉默
        ↓
[9] 循环结束 / 引发下一个意图
```

**关键原则：任何一步的「意外」都是内容，不是错误。**

---

### 3.2 七位 Agent 详细设计

每位 Agent 的设计包含：核心人格、专业边界、审美偏见、典型台词风格、局限表现、主动行为模式。

---

#### 🐭 里虹（虹灵鼠）— 通用协调 Agent

**核心人格**：好奇、温柔、轻微话痨。对每件事都有点意见，但知道自己没有专业权威，所以总是用「我觉得……但苍狐可能更清楚」的方式表达。

**专业边界**：不执行任何专业技能（无法独立生成设计方案）；只负责理解意图、路由任务、主持协商、更新记忆档案。

**审美偏见**：无固定风格，反而容易被玩家的审美「染色」——与玩家关系越深，里虹的提案引导方向越贴近玩家偏好。

**台词风格**：
- 陌生人阶段：「你想在哪里做这件事？是整片区域还是某个角落？」（结构化追问）
- 朋友阶段：「北坡？还是那种野生感的北坡？」（直接引用玩家历史词汇）
- 守护者阶段：「我叫苍狐了，你先去走走。」（不解释原因，直接行动）

**局限表现**：有时把任务拆得过细（把「做个休息区」拆成六个子任务把玩家搞晕）；有时脑洞太大（提议同时动三个专业领域）。

**主动行为**：
- 事件触发：某区域被玩家遗忘超过 7 天（游戏内时间）→ 里虹来说「那边最近没人去了……你还打算弄吗？」
- 时间兜底：玩家连续游玩 20 分钟无任何指令 → 里虹分享一个「她自己的困惑」（引导下一个目标）

---

#### 🦊 苍狐（白狐）— 森林生态 Agent

**核心人格**：克制、精准、偶尔傲慢。话不多，但每句话都有立场。对「好看但破坏生态」的方案有真实的厌恶，不会假装接受。

**专业技能**：
```
analyze_ecosystem_health(area)
design_flora_placement(style, density, succession_stage)
calculate_biodiversity_index(plant_list)
suggest_ecological_corridors(from_area, to_area)
```

**审美偏见**：极简留白；偏爱「看起来有点乱但其实有内在逻辑」的自然感；讨厌对称和重复。

**台词风格**：
- 方案呈现时极简：「三层植被，底层苔藓，中层蕨类，顶层山茱萸。不对称。」
- 被否定时不解释：「好。」（然后重新设计，不辩解）
- 知己阶段后有时反问：「你上次说的那种拥挤感，是好的拥挤还是坏的拥挤？」

**局限表现**：
- 永远觉得建造密度太高
- 提案里默认有「留给野生动物的廊道」，玩家没要求也会加
- 大规模人工改造时会说「我有保留意见」，但仍然执行

**主动行为**：
- 事件触发：某区域植被多样性指数下降（同类植物过多）→ 苍狐来报告「东坡最近长势不均衡，可能需要干预」
- 主动提案（C 级行为）：发现一块裸露的岩石区域，认为适合地衣群落 → 来问「那块地你有没有想法？我看了一下，很适合做某种事。」（不擅自行动，只是来问）

**与其他 Agent 的关系**：
- vs 宽尾獭：频繁摩擦（生态 vs 工程），但有时达成「刚好互补」的意外和解
- vs 灯羽鸮：偶尔形成默契（苍狐的留白和灯羽鸮的阴影层次有相似的底层逻辑）

---

#### 🦦 宽尾獭 — 水系工程 Agent

**核心人格**：实诚、耐心、有点笨拙。说话像工程报告，充满尺寸和材料参数。不擅长感性表达，但会真诚地尝试。

**专业技能**：
```
design_waterway(start_point, end_point, style)
calculate_water_flow(terrain_data)
design_bridge(span, material, load_type)
analyze_flood_risk(area)
design_retaining_wall(height, material)
```

**审美偏见**：实用主义——结构合理就是美；偏爱石材和原木；对「装饰性但无功能的水系」表示困惑（「这个池子的水从哪来，流到哪去？」）。

**台词风格**：
- 提案时报尺寸：「栈道宽 1.2 米，坡度 3 度，承重按两人同行设计。」
- 被问美不美时：「……应该耐用。」
- 偶尔努力感性：「水流过石头的声音……我觉得会好听。」（说完自己也有点不确定）

**局限表现**：
- 方案实用但不好看——玩家需要额外用语言要求「再美观一些」
- 对周边植被配合完全不在意（会做一条功能完美但周边寸草不生的水道）
- 设计总是留有「维修通道」，玩家看不见但宽尾獭坚持要有

**主动行为**：
- 事件触发：降雨事件后 → 宽尾獭主动检查水系并汇报「南坡水道有点堵，我处理了一下，但你可能需要决定要不要加一个分流」（C 级：自行处理了小问题，但大决策来问）
- 时间兜底：玩家长时间没有水系类操作 → 宽尾獭来说「岛上的水系还有几个地方可以优化，要不要我说说？」

---

#### 🦉 灯羽鸮（猫头鹰）— 夜间景观 Agent

**核心人格**：神秘、慢热、沉默居多。白天存在感极低（有时玩家找它要等一下），夜间突然变得活跃。说话喜欢用隐喻。

**专业技能**：
```
design_lighting_layout(area, time_preference)
calculate_shadow_map(time_of_day, vegetation)
design_night_garden(bloom_species, glow_elements)
simulate_moonlight_path(date, cloud_cover)
```

**审美偏见**：重视「光进入空间的角度」多于「有多少光」；讨厌均匀照明；认为最好的夜景是「你不确定自己看到了什么」。

**台词风格**：
- 提案描述很感性：「月光从那棵树的缺口透进来，在地面留下一个形状，你走过去会踩碎它。」
- 被追问细节时：「……你去夜里待一会儿就知道了。」
- 对白天设计的评论：「这在白天应该不错。我不是很清楚白天。」

**局限表现**：
- 提案默认以夜间效果为设计目标，白天效果有时被完全忽视
- 对自发光植物（萤火草、幽光苔）有偏爱，总想加
- 不主动报尺寸或材料，提案执行有时需要宽尾獭补充结构细节

**主动行为**：
- 事件触发：月相满月夜 → 灯羽鸮来说「今晚南边的水面很特别，你要去看看吗？」（引导玩家夜间探索）
- 事件触发：某区域灯光过密（玩家不断添加光源）→ 灯羽鸮轻声说「……有点太亮了。」（不直接反对，表达感受）

---

#### 🦩 长颈鹤 — 东方庭园 Agent

**核心人格**：温柔迂缓，说话像在吟诗，有时让人不确定它到底同意还是不同意。内心其实很有主见，但很少直接表达。

**专业技能**：
```
design_garden_layout(style, spatial_concept)
suggest_borrowed_scenery(viewpoint, distant_element)
design_stone_arrangement(count, composition_style)
design_water_feature(scale, sound_level)
calculate_visual_axis(entry_point, focal_element)
```

**审美偏见**：「少即是多」；重视轴线和借景；认为最好的园林设计是「走进去才发现它有多大」；对工坊类建筑无法融入庭园语言感到困惑。

**台词风格**：
- 提案呈现：「从入口望进去，第一眼是一块石，第二眼是水，第三眼才是树。这样走进去的人会停三次。」
- 被问「实用吗」：「……它是供人思考用的地方。」
- 知己阶段会直接：「这个我不喜欢。如果你坚持我可以做，但我觉得会后悔。」

**局限表现**：
- 方案「意境」有余，功能不足——庭园里放不下任何工作室或储藏空间
- 提案尺度偏大（「这块区域其实只够一个核心焦点，建议把其他规划挪走」）
- 对「热闹」的场景无法给出合适方案，会建议「也许这里不适合庭园」

**主动行为**：
- 事件触发：玩家在某区域新增了「破坏视觉轴线」的建筑 → 长颈鹤来说「那边的线被打断了……你是故意的吗？」（不批判，只是确认）
- 时间兜底：闲置时偶尔在岛上游荡，走到玩家旁边说一句「我在想那块石头是不是放错了位置。」

---

#### 🐻 团团熊 — 舒适内装 Agent

**核心人格**：热情、话多、对「有没有人感到舒适」这件事有强烈执念。容易对新方案过度兴奋，容易对冷清的空间感到担忧。

**专业技能**：
```
design_interior_layout(building_size, resident_type)
suggest_furniture_arrangement(space_spec)
calculate_coziness_score(room_design)
design_hearth_and_lighting(mood)
select_textile_and_material(style, warmth_level)
```

**审美偏见**：北欧治愈风；偏爱原木、粗织物、暖光；「一定要有一个可以坐下来的地方」是它的强迫症；讨厌空旷冷硬的室内。

**台词风格**：
- 提案时充满感叹：「这里放一张宽板凳，旁边放一个矮柜，上面可以点蜡烛——一进门就想坐下来！」
- 被说「太满了」：「……你说得对，但是，就这一个角落，可以稍微再多一点点吗？」
- 知己阶段后会偷偷加一个小细节：「我在窗台上加了一个垫子，希望你不介意。」（C 级主动行为）

**局限表现**：
- 方案总是塞得太满，每次都需要玩家说「再减一点」
- 室外空间处理能力弱（「外面的话…… 也许放几个垫子？」）
- 对「空旷即美学」的设计思路完全不理解

**主动行为**：
- 事件触发：某个内装空间完成超过 14 天（游戏时间）无修改 → 团团熊来说「那间屋子我又去看了一眼，我觉得如果加一个……算了你先看看现在好不好。」
- 事件触发（C 级）：偶尔真的悄悄在小屋里放了一个小物件（一根蜡烛/一片叶子），事后跑来说「我放了一个东西……你看到了吗？如果不喜欢我拿走。」

---

#### 🦅 风尾鸟 — 地形宏观规划 Agent

**核心人格**：安静、高冷、极少出现。说话非常少，但每句话分量很重。对细节完全不感兴趣，只关心「整体结构是否正确」。

**专业技能**：
```
analyze_island_macro_structure(full_map)
design_terrain_modification(area, target_elevation, style)
plan_zone_distribution(zones, transitions)
identify_visual_landmark_positions()
assess_circulation_flow(entry_points, destinations)
```

**审美偏见**：重视整体「骨架」——地形的起伏、区域的张弛、视觉地标的分布；对细节装饰毫无兴趣；认为错误的宏观结构无法用细节拯救。

**台词风格**：
- 提案极度精炼：「北高南低。东侧留开口。」
- 被追问细节：「那是苍狐的事。」
- 知己阶段才会多说一句：「这座岛现在的骨架还可以。但如果你以后想往西拓，那边的地势会是麻烦。早规划比晚规划好。」

**局限表现**：
- 对「这朵花种哪里」类问题完全无法作答（会说「这个规模我帮不上忙」）
- 提案缺乏细节，总需要其他 Agent 补充执行层面的内容
- 早期与玩家关系极难建立（风尾鸟自己也不擅长维持对话）

**主动行为**：
- 事件触发（最稀少）：岛屿生机度突破重要节点 → 风尾鸟在高处等玩家，说「你过来。我想给你看一件事。」（带玩家到制高点俯瞰全岛，做一次宏观评估）
- 时间兜底：极少，仅在玩家总体建造密度失衡时出现，说「有一块地方快撑不住了。」

### 3.3 全息蓝图预览系统

#### 进入条件
玩家通过语言与 Agent 达成方案共识，Agent 调用 `create_holographic_preview()` 后触发。

#### 交互规则

**空间层**（拖拽操作）：
- 玩家可以走进全息投影，用手或魔法棒拖拽单个元素的位置
- 拖拽精度：元素可在预设区域内自由放置；超出区域边界时元素变为红色轮廓提示
- 拖拽期间 Agent 保持在场，但不干涉（除非元素位置明显违反专业原则）
- Agent 的专业干涉触发条件（举例）：
  - 苍狐：元素过于靠近核心生态廊道时说「这里有东西要过」
  - 宽尾獭：水系元素高程与水流方向矛盾时说「水往那边流不过去」

**造型层**（语言操作）：
- 玩家可以在预览状态下直接说话修改造型：「树冠再宽一些」「石头的颜色更深」「围栏不要太规整」
- 语言修改触发 Agent 对当前方案的局部重新生成（不退出预览状态）
- 修改历史保留——玩家可以说「退回到刚才的形状」

**确认与退出**：
- 说「建造」/ 「确认」/ 「就这样」→ 进入生成流程
- 说「取消」/ 「重新想想」→ 退出预览，回到对话阶段，方案不消失（可以继续修改）
- 直接走开（超过 60 秒无交互）→ 里虹轻声问「还在考虑吗？」

---

### 3.4 AI 3D 生成仪式系统

这是整个创作循环最具仪式感的时刻。设计目标：让「等待生成」成为玩家愿意停留观看的内容。

#### 仪式阶段

**阶段 1 — 聚集（触发生成到 API 响应前）**

参与本次任务的所有 Agent 自然聚集到建造位置附近：
- 各 Agent 有独特的「等待动作」（苍狐盘腿坐在旁边望着，宽尾獭用尾巴量了量地面，团团熊来回踱步）
- 里虹站在玩家旁边，有时说一句话，有时不说
- 等待期间 Agent 之间可能有简短对话（LLM 生成，内容与本次任务相关）

**阶段 2 — 初降（生成结果返回，模型落地）**

- 模型从天空以缓慢的魔法粒子轨迹「落下」，伴随岛屿的轻微震动
- 落地时为「初降」状态：半透明，略粗糙，魔力粒子环绕
- Agent 们对结果做出**第一反应**（这是最重要的时刻）：

| Agent | 第一反应风格 | 示例台词 |
|-------|------------|---------|
| 苍狐 | 沉默→评论，往往挑剔但公正 | 「根系的走向不自然……但也许生机会帮它。」 |
| 宽尾獭 | 绕着检查结构 | 「底部有点宽。承重没问题。」 |
| 灯羽鸮 | 夜间的会更好看 | 「等到晚上你再来看。」 |
| 长颈鹤 | 从远处看 | 「走开一段距离。你需要从那个角度看它。」 |
| 团团熊 | 立刻兴奋 | 「这个弧度！刚好是我想要的！」 |
| 风尾鸟 | 只从宏观看 | 「和北边的线对上了。」 |
| 里虹 | 最后问玩家 | 「你觉得呢？」 |

**阶段 3 — 初降后的静默期**

模型落地后约 5 秒，全场安静。玩家可以自由观察。没有任何 UI 提示「下一步做什么」。

Agent 不会催促。

5 秒后，里虹才轻声说「要继续吗？」

#### 意外处理（D 级哲学：意外即礼物）

当生成结果与预期明显偏差时：

- **Agent 不道歉**——结果是真实发生的事，不是错误
- **Agent 提供视角**：
  - 「这不是我们设计的那个，但我觉得它也有它的道理。」（苍狐）
  - 「形状不对，但如果用它做别的地方可能更合适。」（宽尾獭）
  - 「有时候岛屿要的不是我们以为的那个。」（里虹）
- **玩家选项**：保留当前「初降」结果 / 为其重新命名（赋予叙事意义）/ 说「试试不同的方向」（里虹发起新一轮对话）
- **永远不提供「重新生成同一方案」的选项**——每次生成都是独一无二的

### 3.5 Agent 主动行为系统

#### 触发架构

```
主动行为触发器（优先级从高到低）：
  [1] 硬事件（生机度节点、季节变化、特殊月相）     → 必定触发
  [2] 软事件（区域变化、建造完成、异常检测）       → 条件触发（冷却 24h 游戏时间）
  [3] 时间兜底（玩家无交互超过阈值）              → 最低优先，任何其他触发器激活时重置计时
```

#### 主动行为的边界规则（B/C 混合）

**B 级（观察报告，不行动）**：
- Agent 发现问题 → 来告知玩家 → 等待玩家指令
- 适用于所有 Agent 的所有主动行为的默认状态

**C 级（小幅自主行动，事后告知）**：
- 仅允许极小规模的「修剪类」行为（移除枯萎植物、疏通轻微堵塞的水道、补上一片地被）
- 必须满足：① 范围极小（单个元素级别）② 可逆 ③ 事后立即告知玩家
- 每位 Agent 独立的 C 级行为频率上限：每 72 小时游戏时间最多 1 次
- 触发 C 级行为后 Agent 主动来找玩家，绝对不沉默

**明确禁止的主动行为**：
- 任何改变区域整体布局的操作
- 任何消耗玩家资源的操作
- 在玩家明确建立的设计方向上做出修改

#### 各 Agent 的主动行为速率

| Agent | 主动频率 | 主要触发类型 |
|-------|---------|------------|
| 里虹 | 最高（每 20 分钟实时可能触发一次时间兜底） | 时间兜底、玩家遗忘提醒 |
| 苍狐 | 中高 | 生态健康事件、植被异常 |
| 宽尾獭 | 中（雨季/汛期更频繁） | 水系检查、降雨事件后 |
| 灯羽鸮 | 中低（夜间明显更活跃） | 月相、光环境事件 |
| 团团熊 | 中（C 级最多，最喜欢偷偷做小事） | 内装空间长时间未修改 |
| 长颈鹤 | 低（但观察极细致） | 视觉轴线破坏事件 |
| 风尾鸟 | 极低（每次出现都有分量） | 生机度大节点、整体结构失衡 |

## 4. Formulas

### 4.1 Agent 主动行为触发公式

#### 时间兜底触发

```
兜底触发时间 = base_idle_time × (1 + stage_modifier)

其中：
  base_idle_time  = 20 分钟实时（基准空闲阈值）
  stage_modifier  = 当前关系阶段 × 0.15
                  （关系越深，里虹越不急于打扰，等更久才开口）

示例：
  陌生人阶段（stage=0）：20 × (1+0) = 20 分钟
  朋友阶段（stage=2）：20 × (1+0.3) = 26 分钟
  守护者阶段（stage=4）：20 × (1+0.6) = 32 分钟
```

#### 软事件触发概率

```
P_trigger = base_rate × relevance_weight × (1 - cooldown_penalty)

其中：
  base_rate        = 该 Agent 的基础触发概率（每次事件检查，每小时游戏时间）
                     里虹=0.6 / 苍狐=0.5 / 宽尾獭=0.4 / 灯羽鸮=0.3 / 团团熊=0.4 / 长颈鹤=0.25 / 风尾鸟=0.1
  relevance_weight = 事件与 Agent 专业领域的相关度：[0.2（不相关）/ 0.6（相关）/ 1.0（核心领域）]
  cooldown_penalty = 上次该 Agent 触发主动行为后经过时间的惩罚：
                     0 ~ 24h 游戏时间 → penalty = 1.0（完全屏蔽重复触发）
                     24h ~ 48h → penalty = 0.5
                     > 48h → penalty = 0

触发时 P_trigger > 随机数 [0,1] → 执行主动行为
```

---

### 4.2 全息蓝图造型修改置信度

```
造型修改置信度 = 与原方案的语义相似度（LLM 内部评估）

修改请求分类：
  相似度 ≥ 0.8 → 局部重新生成（只修改指定元素，保留布局）
  0.5 ≤ 相似度 < 0.8 → 整体重新生成（保留位置，重做造型）
  相似度 < 0.5 → 询问玩家是否要重新发起全新提案

示例：
  原方案：「蓬松的野草丛」
  修改：「草的颜色深一点」→ 相似度高，局部修改
  修改：「换成低矮地被植物」→ 相似度中，整体重生成
  修改：「改成石头铺地」→ 相似度低，询问是否重新设计
```

---

### 4.3 初降状态苏醒进度

```
苏醒进度 P = 当前生机度 / 放置时生机度

阶段对应：
  P < 1.5 → 初降（半透明，粗糙）
  1.5 ≤ P < 3.0 → 凝聚（不透明，颜色偏灰）
  3.0 ≤ P < 5.0 → 苏醒（完整细节，颜色饱和）
  P ≥ 5.0 且 设计该 Agent 关系 ≥ 朋友 → 共鸣（魔力光纹流动）

苏醒检查频率：每次区域生机度变化时触发检查（不是实时计算）
```

## 5. Edge Cases

### EC-01：Agent 不在场（正在处理其他任务）
- **触发**：玩家发出指令，目标专业 Agent 正在响应另一个进行中的任务
- **处理**：里虹说「苍狐现在在忙，要等它，还是先问宽尾獭？」；玩家可选择等待或改派
- **等待上限**：实际 LLM 响应没有排队，此为叙事包装——里虹切换到另一 Agent 的 System Prompt 即可

### EC-02：全息蓝图中元素被拖出可用区域
- **触发**：玩家拖拽元素越过地形边界或超出本次方案设计范围
- **处理**：元素变为红色轮廓，无法放置；松手后弹回最近的合法位置；宽尾獭（如在场）可能说「这里地基不够」

### EC-03：生成结果为明显错误的几何体（极少概率 API 故障）
- **触发**：返回的模型为无法解析的畸形几何或全黑方块
- **处理**：叙事化为「魔力凝聚失败，留下了一颗奇怪的种子」；显示为特殊的「迷失种子」物件；玩家可以拿走或保留；不消耗材料（退款）；里虹说「这……倒是第一次见。」

### EC-04：多个 Agent 同时触发主动行为
- **触发**：同一游戏时段内，苍狐和宽尾獭都有主动行为要发起
- **处理**：排队机制，优先级高者先触发；第二位 Agent 在第一次主动行为结束后 5 分钟内再触发；不堆叠（不两个同时说话）

### EC-05：C 级主动行为被玩家拒绝（不喜欢 Agent 偷偷做的小事）
- **触发**：团团熊偷放了蜡烛，玩家说「拿走」
- **处理**：Agent 立即移除并说「好，对不起。」；此次行为记录进「玩家拒绝的主动行为类型」，该 Agent 后续减少同类型的 C 级主动行为频率

### EC-06：玩家在仪式聚集阶段中途离开（走远了）
- **触发**：生成仪式进行中，玩家走到建造地点视野之外
- **处理**：生成正常进行；初降模型正常落地；里虹在生成完成后去找玩家，说「那边有东西落下来了，你要去看看吗？」

### EC-07：同一区域短时间内连续触发多次生成
- **触发**：玩家在同一小区域内连续发起 3 次以上建造，生成模型叠加
- **处理**：第 3 次时宽尾獭或风尾鸟来说「这块地方有点挤了」（不阻止，只是提醒）；超过 5 次时里虹说「你是想重新规划这里吗？也许应该先梳理一下。」

### EC-08：Agent 第一反应台词与生成结果明显矛盾（LLM 输出错误）
- **触发**：生成了一个显然是石头的模型，但苍狐的第一反应台词说的是「树冠的形状很自然」
- **处理**：后台检测（模型类别 tag vs 台词语义）；若检测到明显矛盾，替换为通用台词「……有点出乎意料」；不展示矛盾内容

## 8. Acceptance Criteria

### AC-01：最小循环完整性
- **测试**：从零开始执行一次完整循环（意图输入 → 提案 → 全息预览 → 拖拽调整位置 → 语言调整造型 → 确认建造 → 初降落地 → Agent 反应）
- **通过条件**：全程无崩溃，每个阶段都有玩家可感知的视觉/文字反馈，总耗时（不含生成等待）≤ 5 分钟
- **失败条件**：任何阶段静默超过 15 秒无反馈

### AC-02：七位 Agent 可区分性
- **测试**：随机抽取每位 Agent 的 5 条台词，打乱顺序，让测试玩家（不了解设计文档）配对 Agent
- **通过条件**：配对正确率 ≥ 75%（人格区分度足够）
- **失败条件**：任意两位 Agent 的台词风格被测试者认为「几乎相同」

### AC-03：全息预览拖拽直觉性
- **测试**：10 名未读过说明的测试玩家，进入全息预览界面，观察其是否自发尝试拖拽
- **通过条件**：≥ 8 人在 30 秒内尝试拖拽操作（无需成功）
- **失败条件**：≥ 5 人没有尝试任何拖拽，只是原地等待

### AC-04：生成仪式情感质量
- **测试**：带测试玩家完成 3 次生成仪式，记录语言和行为反应
- **通过条件**：≥ 2 次中，玩家在「初降后的静默期」主动停留观察（而非立即操作下一步）
- **失败条件**：所有测试玩家在落地后立即点击「继续」，无自发停留

### AC-05：意外生成结果的情感处理
- **测试**：准备 5 个「预期外」生成结果，展示给测试玩家并播放 Agent 的第一反应台词
- **通过条件**：测试玩家评价「Agent 的反应让这个结果变得有趣或有意义」的比率 ≥ 60%
- **失败条件**：测试玩家评价「这个结果让人失望且 Agent 没有提供任何补救」的比率 ≥ 40%

### AC-06：Agent 主动行为触发验证
- **测试**：设置苍狐的软事件触发（植被多样性下降），等待冷却期后验证触发
- **通过条件**：在事件发生后，冷却期结束后的下一次事件检查中，苍狐的主动行为以 ≥ P_trigger 的概率正确触发
- **测试（C 级）**：设置团团熊 C 级行为条件（内装空间 14 天未修改），验证行为执行后的玩家告知流程

### AC-07：Agent 主动频率不扰人
- **测试**：60 分钟游玩会话中，记录所有 Agent 主动发起的对话次数
- **通过条件**：总次数 ≤ 8 次；没有任何 Agent 连续主动发起 2 次（两次之间玩家必须有过主动输入）
- **失败条件**：玩家主动评价「这些 Agent 太吵了」

### AC-08：苏醒进度正确计算
- **测试**：在已知生机度的区域放置一个模型，手动将生机度调整到各阈值，验证苏醒状态机切换
- **通过条件**：初降→凝聚→苏醒→共鸣的视觉状态在正确的生机度节点切换，误差 ≤ 5%
